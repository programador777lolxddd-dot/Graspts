# Seguridad

## Reportar una vulnerabilidad

Si encuentras un posible problema de seguridad, evita publicar datos personales o detalles que permitan abusar del fallo. Contacta al mantenedor mediante las opciones de contacto que ofrece el perfil de GitHub.

Incluye, si puedes:

- Una descripción clara del problema.
- Los pasos mínimos para reproducirlo.
- El impacto observado.
- Una posible solución, si la conoces.

## Datos y privacidad

- La aplicación actual guarda los gastos en el almacenamiento local del navegador.
- El almacenamiento local no es una cuenta en la nube ni una copia de seguridad.
- Quien tenga acceso al mismo perfil del navegador podría acceder a esos datos.
- No introduzcas contraseñas, datos bancarios ni información sensible en las descripciones de gastos.
- Antes de borrar los datos del navegador, exportar o respaldar los datos importantes por otros medios.

## Alcance

La presencia de esta política no significa que se haya realizado una auditoría de seguridad formal.
