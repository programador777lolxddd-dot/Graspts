# Guía de uso

## Añadir un gasto

1. Abre Graspts.
2. Escribe una descripción fácil de reconocer.
3. Introduce el importe como número positivo.
4. Selecciona una categoría disponible.
5. Pulsa el botón para añadir el gasto.

El total se calcula a partir de los movimientos que aparecen en la aplicación.

## Tema visual

Usa el control de tema para alternar entre modo claro y oscuro. La preferencia puede guardarse localmente en el navegador.

## Almacenamiento

Los movimientos se guardan en el almacenamiento local del navegador. Por tanto:

- No se sincronizan automáticamente con otros dispositivos.
- No hay una cuenta de usuario ni una base de datos remota en la versión actual.
- Borrar los datos del sitio en el navegador puede eliminar los movimientos guardados.

## Consejos

- Usa descripciones breves y reconocibles.
- Revisa el importe antes de guardar.
- Evita incluir datos personales o bancarios en las descripciones.
- Conserva una copia externa de cualquier información que no puedas perder.
